Filters

{{template "settings-subnav" (dict "Active" "filters" "IsAdmin" .IsAdmin)}}

Rules adjust an article's interest score, and scores are additive. A positive rule ranks matching articles higher and makes them likelier to reach your digest and notifications; a negative rule pushes them down. This takes effect immediately, including on articles already scored -- nothing is re-run.

Author, category and tag match the labels a feed publishes. Title, summary and content match the article's own text -- use these for recurring posts whose title changes slightly each time, like a daily open thread. Content rules read whole article bodies, so they are the slow ones and are limited to a handful; prefer title where it will do.

Exact matches the whole value, ignoring case. Contains matches anywhere in it, also ignoring case. Pattern is a RE2 regular expression, matched as written -- start it with (?i) to ignore case. RE2 has no backreferences or lookahead; an expression that does not compile is refused when you add it.

The filter threshold below is separate: it hides articles outright. It compares against the rule total alone, not the adjusted interest score, and it is off unless you set it.

Filter Threshold

0 = disabled (show all articles). Hides any article whose rule total is below this. Rules still adjust ranking when this is 0.

Add Rule

Added to the 0-10 interest score; the result is clamped to that range.
